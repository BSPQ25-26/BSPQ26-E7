Project Summary
---------------

LabLend is a full-stack application (Spring Boot backend, React + TypeScript frontend) for managing borrowing of laboratory equipment.

API Reference
-------------

The Java API documentation (Javadoc) is generated by the build and copied into the built site under `_build/html/javadoc/` — open `javadoc/index.html` from the built documentation to view it.
